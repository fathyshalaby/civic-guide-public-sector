# Challenge requirement map

| Track requirement | Product evidence |
| --- | --- |
| Unstructured or colloquial citizen input | Deterministic workflow matching accepts German and English everyday terms. |
| Plain-language administrative explanation | `plainLanguage`, visible next step, required fields and source rail. |
| Step-by-step service guidance | Every workflow has ordered steps and one-question-at-a-time fields. |
| German and English | Language toggle, localized UI, localized workflow copy and voice input language. |
| Accessible to every population group | Keyboard-visible focus, responsive layout, readable hierarchy, voice input, read-aloud fallback and human handoff. |
| Human contact as fallback | Unknown or low-confidence requests do not invent an answer and show a human-loop state. |
| 1–2 concrete use cases | Residence registration and passport renewal are the hero cases; ID Austria, parking and family allowance are extra packs. |
| Working prototype | Browser flow runs on Cloudflare Pages locally and supports optional ElevenLabs widget. |
| Context on existing government pages | Manifest V3 extension adds a side panel and explicit page-context launcher for `*.gv.at` sites. |
| Strategy paper | `docs/STRATEGY.md` |
| Technical documentation | `docs/TECHNICAL.md` |
| Repository and demo video | GitHub repository plus `docs/DEMO-SCRIPT.md` for a 90-second recording. |
