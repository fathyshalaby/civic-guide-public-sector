# 90-second demo script

## 0:00–0:10 — The problem

“People do not start with a legal procedure name. They start with what
happened to them. CIVIC / GUIDE turns that everyday description into a safe
next step—and a brief a public-service worker can use.”

## 0:10–0:30 — Citizen language

Use the sample: **“Ich bin umgezogen. Was muss ich jetzt erledigen?”**

Show the answer, the confidence signal, the source from oesterreich.gv.at and
the plain-language checklist. Point out that the assistant says what it knows
and asks only for municipality and residence type.

## 0:30–0:45 — Meet the citizen on the page

Open the official passport service page in the CIVIC GUIDE browser extension and
select a confusing passage. Ask: **“My passport has expired. What do I need to
do?”**

Show the “What will be sent?” context review, then show that the page context
becomes a cautious passport workflow with an official source, missing questions
and no claim that the document was renewed.

## 0:45–1:05 — Inclusive access

Switch to English and ask: **“I moved house. What do I need to do now?”** Show
the same source-backed workflow in English. Mention the voice entry point and
the ElevenLabs agent for web, phone and WhatsApp. If credentials are not
available, show the documented phone transcript and the same secured webhook
contract.

## 1:05–1:20 — Human-safe handoff

Show the Civic Desk brief: original words, likely service, facts, missing
information, recommended next step and source. Click **Prepare handoff**, enter
“Wien” and “Hauptwohnsitz”, then confirm. Show the demo case number. Say
explicitly: “This is prepared, not submitted. A real public-service adapter can
replace the mock adapter after the responsible office provides its contract.”

## 1:20–1:30 — Why this can ship

“The workflow registry is source-backed and auditable. ElevenLabs handles the
conversation channels; Cloudflare Pages and Functions keep the integration
small; the same CitizenCaseBrief works across web, browser and phone. The same
shell can add a municipality-specific service without rebuilding the citizen
experience.”
